# 🌦️ Weather Forecast App

A modern **Weather Forecast Web App** built using **HTML, CSS, and JavaScript**, powered by the **OpenWeatherMap public API**.  
The app shows **current weather**, **upcoming forecasts**, **weather icons**, and a **dynamic background** that changes based on weather conditions.

---

## ✨ Features

- 🔍 Search weather by **city name**
- 🌤️ **Current weather** (temperature, condition, icon)
- 📅 **Upcoming forecast** with date & time
- 🕒 Human-readable date format (e.g. _3 February 2026, 9:00 AM_)
- ➡️ **Horizontal scrollable forecast cards**
- 🎨 **Dynamic background** (clear, cloudy, rainy)
- ⚡ Fast & lightweight (no frameworks)
- 📱 Responsive & modern UI

---

## 🛠️ Tech Stack

- **HTML5** – Structure
- **CSS3** – Styling & layout (glassmorphism UI)
- **JavaScript (ES6)** – Logic & DOM manipulation
- **OpenWeatherMap API** – Weather data (Current + Forecast)
